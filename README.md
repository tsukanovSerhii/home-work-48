# React + Tailwind CSS Project (Home Work 48)

Цей проект створено за допомогою Vite та використовує **Tailwind CSS v4** для стилізації компонентів згідно з вимогами домашнього завдання №48. (Початково проект було створено з Material UI, але згодом мігрувано на сучасну архітектуру з Tailwind CSS).

## Опис проекту

Проект демонструє використання утиліт Tailwind CSS в React додатку для створення преміального сучасного дизайну. Були створені наступні компоненти у `src/components`:
- `Header.jsx`: Верхня плаваюча панель навігації.
- `Hero.jsx`: Головний банер.
- `Features.jsx`: Секція з картками послуг.
- `ItemCard.jsx`: Окрема стилізована картка з hover-анімаціями.
- `Form.jsx`: Форма зворотного зв'язку.

Усі компоненти зібрані разом в головному макеті `MainLayout.jsx` та `App.jsx`.

## Інструкції зі встановлення та запуску

1. Клонуйте репозиторій.
2. Переконайтеся, що у вас встановлено Node.js.
3. Перейдіть до каталогу проекту:
   ```bash
   cd home-work-48
   ```
4. Встановіть необхідні залежності:
   ```bash
   npm install
   ```
5. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```
6. Відкрийте браузер за адресою, вказаною в терміналі (зазвичай `http://localhost:5173`).
