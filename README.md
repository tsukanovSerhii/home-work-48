# React + Material UI Project (Home Work 48)

Цей проект створено за допомогою Vite та використовує **Material UI** для стилізації компонентів згідно з вимогами домашнього завдання №48.

## Опис проекту

Проект демонструє використання компонентів Material UI в React додатку. Були створені наступні компоненти:
- `Header.jsx`: Верхня панель навігації (`AppBar`, `Toolbar`).
- `ItemCard.jsx`: Картка з інформацією (`Card`, `CardMedia`, `CardContent`).
- `Form.jsx`: Форма зворотного зв'язку з валідацією стану (`TextField`, `Button`).

Усі компоненти зібрані разом в головному компоненті `App.jsx` за допомогою сітки (`Grid`) та контейнерів від Material UI.

## Інструкції зі встановлення та запуску

1. Клонуйте репозиторій або завантажте файли проекту.
2. Переконайтеся, що у вас встановлено Node.js.
3. Перейдіть до каталогу проекту:
   ```bash
   cd home-work-48
   ```
4. Встановіть необхідні залежності:
   ```bash
   npm install
   ```
5. Запустіть сервер для розробки:
   ```bash
   npm run dev
   ```
6. Відкрийте браузер за адресою, вказаною в терміналі (зазвичай `http://localhost:5173`).
